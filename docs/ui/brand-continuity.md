# Brand Continuity Contract

## Must preserve

- **Foundation:** near-black charcoal surfaces (`#050707` and close existing black values).
- **Accent:** existing teal family led by `#2dd4bf`; teal remains the primary positive/action colour.
- **Type character:** JetBrains Mono and receipt/terminal-style numerical treatment.
- **Mood:** a discreet private vault, with quiet borders and surface separation.
- **Logo:** existing `receiptIt` wordmark and casing.

## May refine

- Surface opacity, border contrast, spacing, radii, shadows, typography scale, focus treatment and responsive density.
- Teal restraint: use it for action, a clear active state and security/protection, not decorative glow.
- Status components so every meaning has text and icon support as well as colour.

## Must avoid

- A blue/purple gradient identity, bright fintech canvas, literal Apple component imitation, pervasive blur/glass, neon decoration, gamification, oversized rounded cards or claims beyond implemented privacy/security features.

## Palette roles

| Role | Token | Existing-brand intent |
| --- | --- | --- |
| Background | `--ri-bg` | Black/charcoal vault foundation |
| Surface | `--ri-surface` | Restrained separation |
| Primary | `--ri-teal`, `--ri-teal-strong` | Capture, active, private/protected |
| Protected | `--ri-success` | Useful proof is stored |
| Review | `--ri-review` | Human confirmation needed |
| Error/rejected | `--ri-error` | Failure or non-purchase only |
| Text | `--ri-text`, `--ri-text-secondary`, `--ri-text-muted` | Clear hierarchy without grey-on-grey ambiguity |
